My Role

As a Gameplay UI Engineer Intern, I supported production UI and gameplay feature development in collaboration with engineering, design, and art. I fixed dozens of bugs that were part of various UI like the tacmap, buy station, custom loadout select, in-game HUD, lootcards, playlist select, and more.


Alongside the bug fixes, I also owned engineering behind Weapon Augments UI from start to finish.

Weapon Augments UI

Weapon Augments seemed like a straightforward feature at first, but implementing it across many areas of the UI revealed different edge cases in each context. Adapting it to those variations gave me broad exposure to the game's UI and taught me to account for how the same feature can behave differently across screens.
