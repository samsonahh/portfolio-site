Chud and Chum - Overview

Chud and Chum is a funny 2-player local co-op fighting game where fish disguise themselves as humans using masks. Rip off the opponent's mask and turn them back into a regular fish. The game was made at NYU Game Center for Global Game Jam 2026, where the theme was Mask.

  • Role: Programmer
  • Platform: PC / Web
  • Engine: Unity
  • Team Size: 6
  • Duration: 3 days
  • Build: Itch.io
  • Source: GitHub

Technologies

C#
Unity
GitHub

My Role

As a programmer on this game jam project, I primarily built movement, combat, and input handling, and implemented most of the gameplay and UI juice in-game. The mashing mechanic really got people riled up when they played, and developing the game with friends was a lot of fun.
